# Chao Companion Game

Unity 6 mobile 2D virtual companion prototype inspired by the care, evolution, and interaction fantasy of Sonic-style Chao gardens.

## Current Direction

- Original cute companion creature rather than a direct franchise copy.
- Mobile-first 2D Unity project.
- Touch gestures drive moment-to-moment interaction.
- Creature stats and mood determine reactions.
- Future behavior memory will let the companion adapt to the player's habits.

## First Milestone

Build a single interactive room scene with:

- placeholder companion sprite or simple shape
- tap, double tap, long press, drag, swipe, and rub detection
- hunger, happiness, energy, trust, curiosity, and mood state
- simple behavior brain that chooses reactions from the current state
- local save system for stats and interaction history
